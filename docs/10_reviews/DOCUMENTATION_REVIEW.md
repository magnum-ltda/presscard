# Documentation Review

## Verificar

- documentação atualizada;
- terminologia consistente;
- dependências corretas;
- diagramas atualizados;
- TODO atualizado;
- decisões arquiteturais registradas quando necessárias;
- documentação não contradiz código confirmado.

## Regra

Não alterar documentação para mascarar um comportamento incorreto. Primeiro decidir se o código ou a documentação está correta.
