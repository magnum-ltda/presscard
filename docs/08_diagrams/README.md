# Presscard Diagrams

## Objetivo

Manter uma representação visual única e atualizada da arquitetura e dos principais fluxos da Presscard.

## Regra

Diagramas são documentação arquitetural. Quando um diagrama contradizer a documentação oficial de arquitetura ou negócio, a inconsistência deve ser resolvida antes da implementação.

```text
Architecture
Domain
Modules
Flows
Integrations
Infrastructure
Deployment
Security
```

## Formato

Preferir Mermaid para diagramas textuais versionáveis.
